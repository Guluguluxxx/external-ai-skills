## Why direct

The pack already separates measured browser evidence from source hypotheses and includes Codex setup guidance. Its six Skills intentionally cross-reference one another, so installing only `web-quality-audit` would be incomplete.

Use it in Web projects rather than globally. It should validate implementation produced under `universal-development-workflow`, not replace project requirements or test suites.
