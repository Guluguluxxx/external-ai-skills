## Use when

Use for an explicit multi-session learning project where structured lessons, exercises, resumable state, and FSRS review are actually wanted.

Do not use it as the default response mode for ordinary questions, one-off tutorials, Obsidian notes, or normal development tasks.

## Optional integrations

Do not install NotebookLM MCP, SciAgent-Skills, context7, Playwright, visual-explainer, or RAG tooling merely because this Skill mentions them.

NotebookLM MCP in particular uses undocumented browser APIs/cookie authentication and requires a separate security decision.
