# external-ai-skills

这是我的**第三方 Skill 来源档案库**。

简单说：我在网上发现一个可能有用的 Skill 后，会先把“它来自哪里、当时看的是哪个版本、能不能复制、后来有没有更新”记在这里。

真正给自己长期使用、已经修改过的版本，放在另一个仓库：`Guluguluxxx/my-ai-skills`。

## 这个仓库是干什么的？

它主要解决三个问题：

1. **记住原作者是谁、原版在哪里。**
2. **记住我上次检查的是哪个版本。**
3. **以后原作者更新时，可以判断哪些变化值得同步到我的版本。**

可以把它理解成：

```text
网上找到的原作者版本
        ↓
external-ai-skills
保存来源和版本记录
        ↓
判断哪些内容值得吸收
        ↓
my-ai-skills
真正给自己使用的版本
```

平时使用 Skill 时，不需要来这个仓库操作。它主要用于以后维护和更新。

---

## 两种保存方式

### 1. 保存一份原版副本

只有原作者的许可证明确允许重新保存时才这样做。

这里保存的是**未经个人修改的原版文件**，方便以后比较更新。

### 2. 只记录来源

如果不适合直接复制原作者文件，就只记录：

- 原作者仓库
- 文件位置
- 当时检查的具体版本
- 许可证
- 检查日期

这样既知道来源，也不会随意复制别人的内容。

---

## 原作者更新后会发生什么？

不会直接覆盖我的版本。

正常流程是：

1. 看原作者更新了什么；
2. 和我现在使用的版本比较；
3. 判断哪些变化有价值；
4. 检查有没有新的权限、依赖或安全问题；
5. 确认后再更新 `my-ai-skills`。

所以即使外部 Skill 更新，也不会突然把我自己的规则改掉。

---

## 文件大概是什么

```text
sources/
└─ 原作者/
   └─ 项目或 Skill/
      ├─ SOURCE.yaml     # 来源和版本信息
      ├─ UPSTREAM.md     # 对原版的说明
      └─ upstream/       # 必要时保存的原版文件

registry.yaml            # 已经跟踪了哪些来源
```

这些文件主要是给 AI 和后续维护流程读取的，不需要日常手动编辑。

---

## 安全原则

- 不保存 Token、Cookie、API Key 或账号登录状态。
- 不保存本机私人路径和个人数据。
- 第三方原版和个人修改版分开管理。
- 未经确认，不让外部更新自动覆盖个人定制版本。
